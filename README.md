# 푸른하루 🌿

2026년의 일정과 할 일을 날짜별로 관리하는 달력형 투두리스트 웹 서비스입니다.  
초록색을 중심으로 한 편안한 화면과 배경을 떠다니는 구름 이모지로 산뜻한 분위기를 담았습니다.

## 주요 기능

- 2026년 월간 달력 탐색
- 날짜별 할 일 추가, 완료, 삭제
- 전체·할 일·완료 상태별 필터링
- 완료한 항목 한 번에 정리
- 날짜별 할 일 개수와 달성 현황 표시
- 브라우저 `localStorage`를 이용한 자동 저장
- 2026년 연간 진행률 표시
- 오늘 날짜 바로가기 및 집중 모드
- 데스크톱과 모바일에 대응하는 반응형 디자인
- 키보드 조작과 스크린 리더를 고려한 접근성 속성

## 디자인 특징

- Pretendard 폰트 사용
- 초록색 중심의 일관된 컬러 시스템
- 그라데이션 없이 구성한 깔끔한 인터페이스
- 배경에서 천천히 움직이는 구름 이모지
- 별도의 장식용 SVG 이미지 없이 달력과 할 일에 집중한 구성
- 움직임 최소화 설정(`prefers-reduced-motion`) 지원

## 사용 방법

1. 달력에서 원하는 날짜를 선택합니다.
2. 오른쪽 또는 하단의 입력창에 할 일을 작성하고 `+` 버튼을 누릅니다.
3. 완료한 항목은 체크박스로 표시합니다.
4. `전체`, `할 일`, `완료` 탭으로 필요한 항목만 확인합니다.
5. 더 이상 필요 없는 항목은 `×` 버튼으로 삭제합니다.

할 일은 현재 브라우저에 자동으로 저장됩니다. 브라우저의 사이트 데이터를 삭제하거나 다른 브라우저·기기를 사용하면 기존 기록이 표시되지 않습니다.

## 실행 방법

별도의 설치나 빌드 과정이 필요하지 않은 정적 웹 서비스입니다.

### 파일을 바로 열기

`dist/index.html` 파일을 브라우저에서 엽니다.

### 로컬 서버로 실행하기

프로젝트 최상위 폴더에서 다음 명령어를 실행합니다.

```bash
py -m http.server 4173 --directory dist
```

이후 브라우저에서 `http://localhost:4173`에 접속합니다.

## 프로젝트 구조

```text
.
├─ dist/
│  ├─ index.html    # 서비스 화면 구조
│  ├─ styles.css    # 디자인과 반응형 스타일
│  └─ app.js        # 달력, 할 일, 저장 기능
└─ README.md
```

## 사용 기술

- HTML5
- CSS3
- Vanilla JavaScript
- Pretendard
- Web Storage API (`localStorage`)

## 데이터 안내

이 서비스는 서버나 계정 없이 동작합니다. 작성한 할 일은 브라우저 내부에만 저장되며 외부로 전송되지 않습니다.
